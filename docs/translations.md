# Translations
Ledger currently supports many languages.
The language used is based on the clients selected language and defaults to `en_us` if it doesn't support the clients language.

### Supported Languages
- `en_us`
- `nl_nl`
- `ru_ru`
- `zh_cn`
- `de_de`

### Contributing
You can contribute support for a new language or improve an old one by submitting a pull request to the [data/edger/lang](../src/main/resources/data/edger/lang) folder.
