# Installation

1. Set up a [Fabric Server](https://fabricmc.net/wiki/tutorial:installing_minecraft_fabric_server) for 1.20.1
2. Install [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
3. Install [Fabric Language Kotlin](https://www.curseforge.com/minecraft/mc-mods/fabric-language-kotlin/)
4. Install Edger from the [Syrup Studios repository](https://github.com/Syrup-Studios/Edger/releases)
5. Run the server
6. Adjust [config](config.md) as needed

For support, report an issue in the [Syrup Studios repository](https://github.com/Syrup-Studios/Edger/issues).
